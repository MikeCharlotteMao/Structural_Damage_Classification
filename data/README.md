# Dataset

The dataset used in this project is the processed Z24 Bridge Benchmark dataset.

It can be downloaded from:

https://huggingface.co/datasets/thanglexuan/Z24-dataset-processed

After downloading, place the following files into this directory:

```
data/
├── inputs.npy
└── labels.npy
```

The repository does not include the dataset because the files exceed GitHub's file size limit.
